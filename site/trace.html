What is being verified?

Record binding, SHA-256 hashes and Ed25519 signatures. Changing a bound value makes the original signature inconsistent with the current evidence.

What if my browser lacks Ed25519?

Supported hashes and record links are still checked. The result is PARTIAL when only signature support is missing; detected mismatches remain INVALID.
