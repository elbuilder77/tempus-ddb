Someone sent you evidence.
Check it without trusting them.

Load the evidence file and the gate public key you obtained separately. The verifier is the same code the tempus CLI runs, compiled to WebAssembly. Nothing leaves this page.

01 / Evidence and key

What you were given.

An evidence bundle (evidence.json from tempus export-bundle), an action trace, a permit, or an outcome receipt. Or paste the JSON below.

Get it from the operator through a channel you trust, not from the file you are verifying. Never paste a key file: only the public key.

Independent by construction.

The verifier trusts only the key you pinned. It does not call the gate, does not read its database and has no private keys. The result is the same tempus.trace-verification.v1 document the CLI prints.

Where does the link come from?
Every permit and outcome receipt the gate signs carries a verify_url pointing here with its action identifier, and every exported bundle carries one with the bundle digest. The link is unsigned on bundles, so this page checks that the link and the file you loaded belong together.
What if VERIFIED is not enough?
VERIFIED means the signed documents are intact and were signed by the pinned gate. It does not show that nothing else happened. For that, compare against a checkpoint (tempus checkpoint verify) or ask the operator for the bundle that includes one.
